# AI Projects Collection

This repository contains a collection of AI and machine learning projects:

1. **Agent Concepts & Workflows**
   - Prompt chaining and routing implementations
   - Agent-based workflows

2. **AI Agent for PostgreSQL**
   - Database interaction using AI agents
   - SQL query generation and optimization

3. **Appointment Management Chatbot**
   - Hospital/Doctor information system
   - Appointment scheduling and management
   - Cancellation and rescheduling features

4. **Image Processing Projects**
   - Super resolution conversion
   - Graph annotation and data extraction
   - Image-to-image recommendation

5. **Educational Tools**
   - MCQ Generator from PDF
   - LLM-Powered Short Answer Scoring
   - Voice Sentiment Analysis

## Setup Instructions

Each project has its own requirements and setup instructions. Please refer to individual project directories for specific setup details.

## Requirements

- Python 3.8+
- Various AI/ML libraries (see individual project requirements.txt files)
- PostgreSQL (for AI Agent project)
- FFmpeg (for voice analysis project)
